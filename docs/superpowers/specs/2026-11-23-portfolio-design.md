# ポートフォリオサイト 設計

## 目的
授業で先生に見せるポートフォリオ。過去に作ったサイトをURL付きで一覧でき、作品を後から簡単に追加できること。GitHub Pagesで公開する。

## ゴール / 非ゴール
- ゴール: 作品一覧（URL・コードへのリンク）、自己紹介、スキル、連絡先。スマホ・プロジェクター表示で崩れない。
- 非ゴール: ブログ、CMS、問い合わせフォーム、ビルド工程。
- アンチゴール: 作品追加のたびにHTMLを編集しないといけない構成。

## アプローチ
- 採用: ビルド不要の HTML/CSS/JavaScript。GitHub Pagesにそのまま置ける。
- 不採用: React等のフレームワーク、Jekyll（授業用途には準備の手間が見合わない）。

## 設計（合意済み）
- 1ページ構成: 自己紹介 → 作品一覧 → スキル → 連絡先・GitHub
- 作品データは `works.js` の配列。項目: title, description, url, repo, tags, image（image/repoは省略可）
- 作品はカードで表示。「サイトを開く」「コードを見る」ボタン
- 内容は仮データ。本人が書き換える
- `README.md` に日本語で編集・公開手順

## 実装者の判断に任せる部分
デザインの見た目、配色、フォント、ダークモード対応。
